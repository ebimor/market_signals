🐛 TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════

  Q: Port 8000 already in use?
  A: Change port in docker-compose.yml:
     services:
       backend:
         ports:
           - "8001:8000"  # Use 8001 instead

  Q: Backend won't start?
  A: Check logs:
     docker-compose logs backend

     If database connection error, wait:
     docker-compose up postgres  # Let DB initialize first

  Q: Can't connect backend to frontend?
  A: Ensure VITE_API_URL matches backend URL
     Check: docker-compose logs frontend

  Q: Database connection refused?
  A: Database needs time to start:
     docker-compose up postgres
     # Wait for "database system is ready to accept connections"
     docker-compose up  # Then start all

  Q: Data disappeared?
  A: If you ran `docker-compose down -v`, volumes are deleted
     Fresh data on next `docker-compose up`

  Q: Want to use SQLite instead of PostgreSQL?
  A: Edit backend/.env:
     DATABASE_URL=sqlite:///./safeswing.db
